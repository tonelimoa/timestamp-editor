# Highlight Tool - 管理者向け技術メモ

保護者向けの使い方は `Highlight_guide.html` を参照してください。
このファイルは、ツールを管理・カスタマイズする方向けの補足情報です。

---

## ファイル構成

| ファイル | 役割 |
|---|---|
| `Highlight_guide.html` | 保護者向けの使い方ガイド（最初に開くファイル） |
| `index.html` | タイムスタンプ記録ツール（動画ファイル／ライブ映像を1画面で切り替え可能） |
| `Make_highlight.py` | ハイライト動画を自動生成するメインスクリプト（`timestamps.txt` 用） |
| `run.bat` | `Make_highlight.py` を実行するバッチファイル |
| `timestamps_sample.txt` | タイムスタンプファイルの記入例 |
| `videos/` | 元動画（MP4）を入れるフォルダ（同梱済み。中にMP4を入れて使う） |
| `output/` | 生成されたハイライト動画の出力先（自動作成） |
| `bgm.mp3` | BGMファイル（サンプル曲同梱済み。お好みの曲に差し替え可） |

## index.html について

`index.html` は以下の軸を切り替えられます。

- **動画入力**：画面上部のタブで「📂 動画ファイル」⇄「📷 ライブ映像（OBS仮想カメラ等）」を切り替え
  - ライブ映像モードでは、ストップウォッチの開始・停止を `Num+` / `Num-` キーで操作できます（OBSの録画開始・停止ホットキーと同時押しする想定）。計測中はシーン一覧の確認・削除・手動追加がロックされます。
- **記録方法**：選手ボタンをタップしてSCENEを記録します。選手名・大会名・対戦相手・前後秒数（シーンごとに調整可）を記録し、`timestamps.txt` を出力します。

### シーンの並べ替え（ドラッグ＆ドロップ）

各SCENEカード左端の「⠿」ハンドルをドラッグすると、シーン一覧の順序を自由に入れ替えられます（PC・スマホどちらでも操作可）。並べ替えた順序がそのまま出力ファイルの行順になります。計測中（ロック中）は並べ替えできません。

### 選手を絞り込んで出力

「シーン一覧」見出し横のセレクトで特定の選手を選ぶと、その選手のシーンだけが一覧に表示されます。この状態で「📥 出力」すると、選手名を含むファイル名（例: `timestamps_田中.txt`）で、その選手のシーンだけが出力されます。「表示: 全員」に戻すと、従来通り `timestamps.txt` として全シーンを出力します。
※「✂️ 分割保存」は選手の絞り込みに関わらず、常に全選手分のシーンを対象にグループ分割して保存します。

## カスタマイズ可能な設定値

`Make_highlight.py` の先頭付近にある定数を変更することで、挙動を調整できます。

| 定数 | 内容 | 初期値 |
|---|---|---|
| `BGM_VOLUME` | BGMの音量（元音声に対する比率） | `0.5` |
| `FADE_DURATION` | クリップ間のフェード秒数 | `0.5` |
| `FONT_CANDIDATES` | テロップに使うフォントの優先順位リスト | 游ゴシックBold等 |

`index.html` 側の定数：

| 定数 | 内容 | 初期値 |
|---|---|---|
| `PRE_SEC` / `POST_SEC` | 切り出し前後秒数のデフォルト値（シーンごとに調整可） | `7` / `3` |

## timestamps.txt の形式

```
# 書式: file=ファイル名, ts=タイムスタンプ, pre=前(秒), post=後(秒), event=大会名, opponent=対戦相手, date=日付, player=選手名
file=game1.mp4, ts=12:34, pre=10, post=15, event=春季大会, opponent=××FC, date=2026-06-07, player=田中
```

- 各項目は `キー=値` の形式で、カンマ区切りで並びます。
- 「対戦相手」を入力すると、テロップ1行目に「大会名　日付　VS ○○」として表示されます。
- 対戦相手が無い場合（練習試合など）は空欄でOKです。

## フォントについて

テロップ用フォントは `FONT_CANDIDATES` リストの上から順に存在確認し、最初に見つかったものを使用します。
游ゴシック・メイリオが入っていない環境では、自動でMS Gothic等にフォールバックします。

文字が小さくピクセル表示になる場合は、`FONT_CANDIDATES` の並び順を確認し、Bold系のフォント（`YuGothB.ttc` など）が優先されているか確認してください。

## トラブルシューティング（技術編）

| 症状 | 対処 |
|---|---|
| `python` / `ffmpeg` が見つからない | 環境変数PATHの設定を確認（ガイド内「コマンドプロンプトの基本」参照） |
| `UnicodeDecodeError` 関連のエラー | `Make_highlight.py` 内の `subprocess.run` に `encoding="utf-8", errors="replace"` が設定されているか確認 |
| `filter_complex` の parse エラー | drawtext構文ではなくPillowによる画像合成方式に切り替え済み。古いバージョンを使っていないか確認 |
| 選手名・大会名・対戦相手リストをリセットしたい | ブラウザの開発者ツールでlocalStorageの `hl_roster_players` / `hl_events` / `hl_opponents` を削除 |
